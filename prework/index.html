Pre-work

Prerequisite

Expected complete before Week 1

Modules B01 to B08 are a prerequisite, not part of the course. They are self-paced and are not taught in class. Arrive at Week 1 with them done.

They are checked, not taught: the labs verify them with teaching assistants in the room, in two passes, and the Week 2 Setup Gate closes the pre-work.

The two verification passes.
Where Modules verified
Week 1, the environment and git exercise B01 to B05
Week 2, the git, GitHub and Setup Gate exercise B06 to B08

Modules

The eight modules

Pre-work modules. Each module page is linked here once it is published.
Module Title Covers Page
B01 Accounts and a shell GitHub account with 2FA; OpenRouter (no card); a real Unix prompt via WSL2, Homebrew or apt; the /mnt/c rule. Page to be linked when published
B02 The terminal Paths; cd, ls, pipes, $HOME; editing a dotfile; reading an error down to the failing line. Page to be linked when published
B03 Identity and keys gh auth status clean; one API key at mode 600, loaded by a guarded line. Page to be linked when published
B04 VS Code Open a folder; the integrated terminal; install an extension; edit settings.json as a file. Page to be linked when published
B05 Environments Create and activate the course environment from environment.yml. Page to be linked when published
B06 Git by hand init, stage, commit, branch, push, pull from the command line, no GUI. Page to be linked when published
B07 GitHub workflow Branch; pull request; read a red check down to the failing line; squash-merge. Page to be linked when published
B08 Markdown, YAML, JSON Write all three by hand; validate each with a parser. Page to be linked when published
